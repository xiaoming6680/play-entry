## 概念方向（最初的 A/B/C 已被下方「方向更新」取代，仅保留作记录）

### A. 星图：可以玩的入口
- 漆黑的宇宙里，你是一个发光的小点（鼠标/触屏引导，键盘也行），每个游戏是一颗星球，带着各自游戏的 DNA：
  - **beat 星**：跟着 BPM 脉动的霓虹星球，靠近时能听到它的音乐由远及近（空间音频，需用户手势后才发声）
  - **stay 星**：你靠近它它会"看"你，你离开时它会挽留你
  - **dot 星**：只是一个像素，靠近时它的画风一层层进化
- 飞进星球 → 镜头推进的转场 → 跳到对应子域名
- 还没上线的游戏是"正在成形"的暗星；以后新游戏 = 新星球
- 藏几个彩蛋（Konami 码、长时间不动会发生什么……）

### B. 街机厅
3D 街机厅（three.js），每台机器的屏幕放着游戏的演示画面，CRT 辉光；点击机器镜头推进屏幕，屏幕变成游戏。

### C. 假操作系统
复古桌面系统，游戏是桌面图标，双击启动；回收站、终端命令、一个关不掉的窗口等彩蛋。

## ★ 方向更新（2026-10-05，用户指定，取代上面 A/B/C 的推荐）

### 参考资产
`D:\!XM的项目\第三方参考\RhineLabUI` —— 用户之前 fork 的项目：《明日方舟》「莱茵生命：访问」PV 终端界面的非官方复刻（TypeScript + Three.js + Vite）。白底开场 → 半透明玻璃档案盒组成的循环阵列 → 抽取 → 磨砂玻璃解密变清晰 → 阅读档案。先读它的 `README.md`、`DESIGN.md`，看 `docs/media/` 里的截图和动图，需要时读 `src/`。**只读，不要改那个目录。**

用户原话的意思：这个网站很酷炫，但**不要照搬，要吸取其中的设计**，比如把一份份资料做成卡带，以它为资产做入口页。

### 核心转译：档案盒 → 游戏卡带
- 每个游戏是一盒半透明玻璃卡带，排成可循环滑动的阵列；选中时卡带抬起、阵列泛起波浪
- "读取"时磨砂外壳自上而下变清晰，露出卡带内部**活的核心**——各游戏的 DNA：
  - **beat**：内部的环跟着 BPM 脉动发光
  - **stay**：内部有个会追着指针看的"眼睛"/指示灯，你要离开时它有反应
  - **dot**：内部只有一个像素，读取时一层层进化（终端 → 8-bit → 辉光 → 3D）
- 旁边的正文同步"解密"出游戏信息：名称、一句话、类型、时长、状态、建议设备
- 启动：卡带"插入"/镜头推进的转场演出 → 跳到对应子域名
- 目前只有 3 个游戏，阵列要想办法撑满：比如空白卡带（"下一个游戏"）、按 已上线 / 开发中 / 实验 分列，或别的办法，设计阶段给出方案
- 开发中的游戏：卡带可以看、可以读取，但插入后给一个"还在开发"的小演出，而不是死链接

### 可以吸取的设计语言
细线 + 紧凑中英混排的 HUD；开场序列（逐字输入 → 标志绘制 → 接入）；滚动数字/文字（`@kitlangton/rolling-number`，MIT）；临界阻尼的升降与带惯性的拖动；阵列波浪传播；磨砂 → 清晰的解密揭示；清脆的玻璃交互音；明暗两套配色；手机端手势、安全区、竖屏布局的处理方式。

### 红线：不照搬
- 不用莱茵生命 / 明日方舟的名称、标志、文案、角色名（如 JOYCE MOORE）、品牌位置；入口要有**自己的品牌身份**（名字在设计阶段提几个给用户选）
- 配色可以借鉴"暖灰白 + 一个强调色"的克制思路，但要做出自己的配色，不复制它的色值组合
- 不直接用它的 GLB 模型（非 MIT 授权，且是原作视觉的衍生）：卡带模型自己做（three.js 程序化建模，或新做轻量 GLB）
- 不用它的音频（boot-intro.ogg、bgm-loop.ogg 等权利归原作者）：声音用 WebAudio 自己合成
- 不用 Novecento 字体（单独授权，限定用途）；MiSans 可以用，遵守其许可并保留署名
- 它的程序代码是 MIT：可以参考或摘用具体实现（阻尼运动、阵列循环、手势分解等），摘用的文件保留 `Copyright (c) 2026 LBEILC` 的 MIT 声明

### 性能
RhineLabUI 完整资源约 34 MiB，入口必须轻得多：首屏先出 2D 的 HUD 和文字，3D 延后加载；手机和微信内置浏览器要流畅；不支持 WebGL 时降级成好看的 2D 版本。

## 关键要求
- **手机必须能用**：链接多半是从抖音/微信里点开的，入口要在手机和微信内置浏览器里流畅好看（游戏本身是桌面优先，入口上要标出"建议电脑游玩"）
- **秒开**：首屏尽快出现，重资源延后加载；不支持 WebGL 或开启"减少动态效果"时降级成好看的静态版
- **数据驱动**：游戏列表放在一个数据文件里（名称、地址、简介、状态、主题色、预览图），加新游戏不用改代码
- **分享卡片**：配好 `og:title` / `og:image` 等 meta，链接发出去有像样的预览图
- **不依赖游戏本体**：入口里的卡带/预览是入口自己画的风格化表现，不 iframe 嵌入游戏
