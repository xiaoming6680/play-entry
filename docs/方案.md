## 概念方向（推荐 A，可在设计阶段调整或混合）

### A. 星图：可以玩的入口（推荐）
- 漆黑的宇宙里，你是一个发光的小点（鼠标/触屏引导，键盘也行），每个游戏是一颗星球，带着各自游戏的 DNA：
  - **beat 星**：跟着 BPM 脉动的霓虹星球，靠近时能听到它的音乐由远及近（空间音频，需用户手势后才发声）
  - **stay 星**：你靠近它它会"看"你，你离开时它会挽留你
  - **dot 星**：只是一个像素，靠近时它的画风一层层进化
- 飞进星球 → 镜头推进的转场 → 跳到对应子域名
- 还没上线的游戏是"正在成形"的暗星；以后新游戏 = 新星球
- 藏几个彩蛋（Konami 码、长时间不动会发生什么……）

### B. 街机厅
3D 街机厅（three.js），每台机器的屏幕放着游戏的演示画面，CRT 辉光；点击机器镜头推进屏幕，屏幕变成游戏。

### C. 假操作系统
复古桌面系统，游戏是桌面图标，双击启动；回收站、终端命令、一个关不掉的窗口等彩蛋。

## 关键要求
- **手机必须能用**：链接多半是从抖音/微信里点开的，入口要在手机和微信内置浏览器里流畅好看（游戏本身是桌面优先，入口上要标出"建议电脑游玩"）
- **秒开**：首屏尽快出现，重资源延后加载；不支持 WebGL 或开启"减少动态效果"时降级成好看的静态版
- **数据驱动**：游戏列表放在一个数据文件里（名称、地址、简介、状态、主题色、预览图），加新游戏不用改代码
- **分享卡片**：配好 `og:title` / `og:image` 等 meta，链接发出去有像样的预览图
- **不依赖游戏本体**：入口里的"星球"/预览是入口自己画的风格化表现，不 iframe 嵌入游戏

## 技术约束
- 纯前端静态站点，部署在 Cloudflare Pages + 自定义子域名 `play.xiaoming6680.link`，产物放在根路径下
- 最好双击 `index.html` 就能看；需要构建就用 Vite
- 界面文案用简体中文
