## 构建：为什么能双击打开

浏览器用 `file://` 打开时，会把 `type="module"` 脚本和带 `crossorigin` 的资源当成跨域拦掉。所以 `scripts/build.mjs` 做了两次 Vite 构建，都输出 **IIFE 经典脚本 + 相对路径**：

1. 主包 `assets/main.js`（约 23KB gzip）：HUD、开场、核心、2D 版、声音。`site-html.mjs` 把 `<script type="module">` 改成 `<script defer>`，并去掉 `crossorigin`
2. 3D 包 `assets/scene3d.js`（约 143KB gzip，绝大部分是 three.js）：主包运行后插入 `<script>` 懒加载，挂在 `window.MingkeScene3D`

开发时走 Vite 正常的 ES module 和 `import()`（`import.meta.env.DEV` 分支，生产构建时会被摇掉）。

`content/games.json` 在构建时打进主包，同时由 `site-html.mjs` 生成 `<head>` 里的分享 meta 和 `<noscript>` 游戏列表。所以改完数据要重新 `npm run build`。

## 渲染档位与调试参数

| 参数 | 作用 |
|---|---|
| `?r=3d` / `?r=2d` / `?r=static` | 强制 3D / 2D / 静态版（不写入偏好） |
| `?boot` | 强制播放开场（同一会话默认只播一次） |
| `?skipboot` | 跳过开场 |
| `?shot=og` | 分享图构图（隐藏面板，显示品牌卡） |
| `?shot=<游戏 id>`、`#<游戏 id>` | 停在那一盒 |

自动选择：系统开了「减少动态效果」→ 静态版；没有 WebGL2、开了省流量，或用户在「关于」里选了 2D → 2D 版；其余 3D。触屏设备用轻量 3D（像素比 ≤ 1.5、最多 1900 盒、核心贴图 384/96）。3D 进场后前 150 帧平均超过 50ms 会自动降到 2D；WebGL 上下文丢失也会降到 2D。

控制台可用 `__mk`（`openRead()`、`doInsert()`、`rail`、`items()`）调试。

## 3D 实现要点

- **不用屏幕空间折射**（`MeshPhysicalMaterial.transmission` 在手机上太贵）。卡带正面是自己的着色器：按视线方向偏移去采样核心贴图，模拟核心在玻璃后 0.24 的深度；磨砂度决定模糊（主角卡带 10 点圆盘模糊，其余用图集的 mip）和乳白度；解密是一条自上而下的羽化前沿 + 红色读卡头
- 整片仓库一个 `InstancedMesh`（盖面 + 侧面两个材质组），每盒只带四组实例属性：图集格、贴签格、磨砂/解密、颜色/状态灯。一帧两次绘制调用
- **雾不混颜色而是变透明**：远处的卡带直接融进页面的 CSS 渐变背景，明暗切换也自然（画布 `alpha: true`，输出预乘 alpha）
- 主角核心（选中那盒）每帧重画、全分辨率；其余核心画进小图集，20fps（触屏 12fps）
- **铺满不露边**：每帧在屏幕上取 4×4 个点打射线，和卡带底面、顶面两个高度求交，得到可见区域的包围盒（射线朝天或超过雾的远端就截在雾的远端）；再对包围盒里每个卡位做视锥球体测试，按离镜头由近到远排好写进实例（近的先画，减少过度绘制），超过上限丢最远的
- **开场镜头**：`Frame.intro`（0..1）不走弹簧，直接在「特写」和「浏览」两个机位之间插值（距离按对数插值；方位角、仰角略领先于距离，先抬高转开再拉远，形成一条弧线）；这期间选中卡带悬浮在架子上方（`introLift`），镜头抬到能越过前排时落回卡位，镜头目标点前段跟着卡带一起下降，卡带一直在画面中间。`Frame.ignite` 是点亮波的秒数，半径 2.5 + 30·t^1.7 卡位，每盒卡带算出自己被点亮的时刻，用实例属性 `aE`（可见度、闪光）淡入、升起、闪一下
- **推近对位**：开场画布上的标志轮廓（40×46 坐标）要落到 3D 卡带正面的四个屏幕角（`faceQuad()`，2D 版取最前面那张卡片的矩形）。标志框和卡带框之间"缩放 + 平移"有一个不动点，绕它按对数插值缩放倍数，就是镜头匀速推进的感觉，「铭刻」文字也用同一个不动点、同一个倍数做 CSS 缩放；终点再用双线性映射补上透视偏差，圆角半径从标志的 3 过渡到实物的 1.4，切角比例本来就一致，所以能严丝合缝地贴上去。`Opening.tick()` 只推进时间，`paint()` 在舞台画完之后才画，每帧拿到的都是最新的卡带位置，镜头开始动时轮廓也贴得住
- **颜色光**：着色器按到选中卡带的距离加一层它的颜色（浅色主题相乘、深色主题相加）；主色太浅时用第二色。画面上另有一层 CSS 光晕（浅色 `multiply`、深色 `screen`）
- 选中、悬停的抬起用每盒独立的阻尼弹簧；读取那盒「先升起、再转正」，返回「先转正、再下降」
- **坑**：实例属性里的格子编号经过插值会在 3.9999 / 4.0001 之间跳，`mod` 之后跳到别的格子，表现为贴签上满是黑色噪点。必须先 `floor(x + 0.5)` 取整。另外，带隐式导数的采样不要放在分支里（mip 级别会算错）

## 新增一种专属核心

1. 在 `src/cores/` 写一个返回 `Core` 的函数（`draw(g, size, state, item)`），用 `plate()` 画底板、`inWell()` 画井内
2. 在 `src/cores/index.ts` 的 `make()` 里注册
3. 在 `src/types.ts` 的 `CoreKind`、`scripts/check-data.mjs` 的 `CORES` 里加上名字
4. 数据里写 `"core": "名字"`

不写专属核心时，用 `generic`（数据里给 `glyph` 和颜色即可）。
