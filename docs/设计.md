# 游戏总入口 设计稿

> v0.1 · 2026-10-05 · **已确认**（用户：按推荐来），第一版已实现。方向依据 `docs/方案.md` 的「★ 方向更新」。文中带"初值"的数字在实现时按实际画面调过；实现细节、自测记录见 [开发说明.md](开发说明.md)。

## 0. 一句话与体验目标

**一座装满玻璃卡带的仓库。每个小游戏是一盒卡带：翻找、抽出，看磨砂玻璃一点点变清晰、露出它活着的核心，然后插进去开玩。**

按优先级：

1. **1 秒内**出现好看的第一屏（手机 4G、微信里也一样）
2. **10 秒内**让人"哇"一下：第一次抽出卡带、玻璃变清晰的那一刻
3. **30 秒内**弄清楚有哪些游戏、哪个能玩、该用什么设备玩
4. **愿意多待一会儿**：翻卡带的手感和声音、核心的小互动、彩蛋

## 1. 方向与理由

选定：**玻璃卡带库**。借鉴 RhineLabUI 的「玻璃档案盒阵列 + 抽取 + 磨砂解密」，转译成自己的卡带、品牌和配色。

- 参考作品最打动人的是三件事：成片阵列的秩序感、抽出一份的仪式感、磨砂变清晰的揭示。这三个动作合起来，正好就是"挑一盒卡带"
- 卡带是游戏最经典的实物隐喻。"插入卡带"让跳转有了仪式感，"开发中"也有了物理含义：**还在刻录**
- 好扩展：加一个游戏，就是架子上多一盒卡带，布局不用重新设计
- 手机友好：浏览只沿一个方向（上下翻），和抖音用户的滑动习惯一致
- 原先星图方案里的好点子保留到核心和彩蛋里：stay 会看你，beat 跟着节拍跳，dot 一层层进化

## 2. 从 RhineLabUI 吸取了什么，怎么转译

| 设计点 | RhineLabUI 的做法 | 我们的转译 | 实现 |
|---|---|---|---|
| 阵列的秩序感 | 暖白空间里，同款档案盒成片排成循环阵列 | 冷雾色空间里一排排玻璃卡带架。中间主架上的卡带透出各自游戏的颜色，两侧是还没刻录的空白卡带 | 自写场景；循环寻址摘用 `nearestOccurrence` |
| 选中抬起 + 波浪 | 选中的档案浅抬起，同时向四周传出有正负波谷的波 | 保留，这是手感的核心。波从选中的卡带沿架子传开；读取 beat 时，整片仓库跟着 BPM 轻轻一颤 | 摘用 `damp` `smooth` `baselineSelectionWave` |
| 停手后呼吸 | 停手 2.5 秒后，渐入 8 秒和 13 秒两个周期叠加的起伏 | 保留思路，重调幅度和周期；发呆更久会触发彩蛋 | 摘用 `idleWave` 并改参数 |
| 拖动手感 | 屏幕位移经 2×2 投影逆矩阵分解到两条轨道，松手后惯性滑行再吸附 | 以一维为主（沿架子翻），横向拖动带橡皮筋 | 改编 `ArchiveDrag` `ArchiveMomentum` |
| 抽取 → 特写 | 卡片升高，镜头转向，左边模型、右边正文 | 保留构图逻辑；竖屏改成上面卡带、下面正文 | 自写镜头 |
| 磨砂 → 清晰 | 黑色对角线伸展、收束后，盖板自上而下由磨砂变清晰（约 3.6 秒） | 改成**读卡头**：一条录制红扫描线自上而下扫过，扫过的地方变清晰，全程约 1 秒（手机用户等不了 3.6 秒） | 自写视差着色器；羽化前沿参考 `glassRevealAtHeight` |
| 正文同步解密 | 每行文字盖一条墨块，按顺序先加速、再长长地减速滑走 | 保留节奏，墨块改用该游戏的主题色；标题用滚动文字 | 改编 `DocumentDecryption` |
| 滚动数字和文字 | `@kitlangton/rolling-number`，460ms | 自写一个轻量版（等宽数字 + 整串标题上下滚），省一个依赖 | 自写 |
| 细线 HUD、中英混排 | 左上三行品牌字、右上工具、左下大号计数、底栏小字 | 保留"细线 + 紧凑排字 + 大量留白"的气质，版式换成**取景框**：选中卡带的四个角投影出取景框角标并跟着它走，左上有 REC 指示，编号和时码用等宽字 | 自写 |
| 开场 | 逐字输入 → 圆环和 Logo 绘制 → 身份验证 → 欢迎 → 白场 → 阵列滑入，约 20 秒 | 压到 2–3 秒：一行逐字输入 → 自己的标志描线 → 品牌三行错开出现 → 仓库从下方按波浪升起。可跳过，同一会话里第二次不播 | 纯 CSS/SVG，JS 还没加载就能开始播 |
| 玻璃音 | 短起音、不等间隔的共鸣、快速衰减；切档、抽取、归位各有区分 | 同样的思路，用 WebAudio 现场合成，不用任何录音 | 自写 |
| 明暗两套 | 暖灰白 / 近黑 + 琥珀；切换从选中单元按距离延迟扩散 | 自己的「雾」「夜」两套配色，保留扩散式切换 | 自写 |
| 手机适配 | 安全区、44px 触控、滑动阈值、竖屏布局、软键盘 | 全部吸收，另外针对微信内置浏览器做处理 | 自写 |
| 性能 | 四档画质 + 超级性能模式，靠用户手动选 | 自动分档：完整 3D / 轻量 3D / 2D / 静态 | 自写 |

## 3. 红线落实清单

- **名称、标志、文案**：不出现莱茵生命、明日方舟、RHINE LAB、JOYCE MOORE 等；品牌、标志、全部文案原创
- **配色**：不用暖灰白 + 杏金 / 琥珀；我们用冷雾 + 录制红（见 §5）
- **模型**：不用它的 GLB；卡带由 three.js 程序化建模，形状是我们自己的（竖版、切角、圆形核心井）
- **音频**：不用它的任何音频，全部 WebAudio 合成
- **字体**：不用 Novecento。默认用系统字体 + 一个开源等宽字体（OFL）。MiSans 体积大，第一版不用；以后要用，按它的许可保留署名
- **代码**：只摘用通用的运动和输入算法。每个摘用文件的头部保留 `Copyright (c) 2026 LBEILC` 和 MIT 声明，产物附 `licenses/RhineLabUI-MIT.txt`，「关于」里列出致谢
- **版式**：不复制它的品牌三行字样式，也不用右下角 POWERED BY 的署名位

## 4. 品牌

| 候选 | 英文 / 副标 | 含义 |
|---|---|---|
| **铭刻**（推荐） | MINGKE · CARTRIDGE ARCHIVE | 小铭的"铭" + 刻录卡带的"刻"。"铭刻"本义是刻在器物上，正好对应玻璃卡带；开发中 = 刻录中 |
| XM-6680 | 卡带式游戏机 | 把入口当成一台虚构的游戏机，型号取自域名，"插入卡带 → 开机"最顺 |
| 小铭卡带社 | XM CART CLUB | 直白、亲切 |
| 无聊而 vibe | BORED & VIBING | 沿用游戏目录的名字，气质随性 |
| 6680 号仓库 | DEPOT 6680 | 呼应卡带仓库的空间感 |

推荐「铭刻」，也可以和 XM-6680 组合：品牌叫「铭刻」，「XM-6680」作为设备铭牌出现在 HUD 小字里。卡带编号前缀跟品牌走（铭刻 → `MK-01`）。品牌名和编号前缀都写在数据文件里，改名不用改代码。

**标志**（自己设计）：一个竖版圆角矩形，右上角切掉一角（卡带轮廓），中间一个实心小圆（核心）。开场时用描线动画画出来：先画轮廓，再"滴"出中间的点。favicon 用同一个图形。

## 5. 配色与字体

| 用途 | 雾（亮） | 夜（暗） |
|---|---|---|
| 背景 | `#E9EBEE`，顶部渐亮到 `#F4F5F7` | `#0B0D10`，顶部渐变到 `#13171C` |
| 正文 | `#0F1216` | `#E8EBEE` |
| 辅助文字 | `#626A74` | `#8B939D` |
| 细线 | `#B8BEC6` | `#2B3139` |
| **强调：录制红** | `#FF3B2F` | `#FF4B3E` |
| 玻璃外壳 | 乳白 `#F3F5F7`，边缘偏冷 `#DCE4EA` | 烟灰 `#1A1F26`，边缘 `#2E3843` |
| 远处雾色 | `#E4E7EB` | `#0E1115` |

- 强调色只用在四个地方：REC 指示、读卡头扫描线、主按钮、开发中状态灯。其余全靠灰阶，**颜色留给游戏核心**
- 默认跟随系统的深浅色设置；HUD 里可以切换，并记住选择
- 游戏色取自各游戏的气质：beat 品红 `#FF2E88` + 青 `#22E5FF`；stay 纸白 `#F4F1EA` + 墨 `#111111` + 一点情绪粉 `#FF8FA3`；dot 终端绿 `#3BFF6E`，之后每个时代用自己的调色板；空白卡带无色

字体：

- **中文**：系统字体栈（PingFang SC / HarmonyOS Sans SC / MiSans（系统已装时）/ Noto Sans CJK / Microsoft YaHei），零下载
- **编号、时码、英文小标**：JetBrains Mono（OFL），只取拉丁子集，约 20KB，内联进 CSS，这样双击打开也能用上
- 为什么用等宽：卡带编号、时码、REC 都是"设备"的语言，也和参考作品的宽体无衬线拉开了距离

## 6. 卡带模型

**尺寸**（世界单位，初值）：宽 3.2 × 高 3.8 × 厚 0.44，竖版，比例接近掌机卡带。参考作品是横版薄档案盒（5 × 3.7 × 0.31），两者剪影一眼就能分开。

**部件**：

- **外壳**：圆角 + 右上切角，用 2D 轮廓挤出成形（带小倒角），乳白磨砂玻璃
- **顶脊**：卡带立在架子上时，从上方看到的就是这条边。左端一段游戏色色标；右端一颗状态灯（开发中 = 红色慢闪，可游玩 = 绿灯常亮，空白 = 灭）；中间压印编号 `MK-01`
- **正面**：整面玻璃，上部 5 道防滑横纹（画在贴图里）
- **内部**：内衬板 + 圆形核心井（核心就在这个圆里活动）+ 底部一排铜色触点（"金手指"，隔着玻璃也看得到）
- **贴签**：左下一张不透明的小贴纸（编号 + 中文名 + 游戏色条）。它贴在玻璃外面，所以磨砂时也看得清

**渲染办法**（关键）：

- **不用屏幕空间折射**，它在手机上太贵。正面改用自己写的**视差着色器**：
  - 采样"核心贴图"时按视线方向偏移，模拟核心在玻璃后面约 0.2 的深度
  - 磨砂度决定模糊半径和乳白程度
  - 再叠一层细噪声，做出磨砂颗粒和高光条
- 不需要透明排序，也不需要额外的渲染通道。解密就是一条从上往下走的清晰前沿（带羽化），前沿处画读卡头红线
- 整片仓库几百盒卡带只用**一个 InstancedMesh**。核心贴图打成图集（beat、stay、dot、空白、通用各占一格），每盒只带几个参数：用哪一格、磨砂度、抬起高度、状态灯。一次绘制调用就能画完整片仓库
- **光会渗出来**：外壳的自发光按核心颜色轻微染色，所以远处的 beat 卡带看起来是淡淡的品红玻璃

**状态**：

| 状态 | 抬起 | 磨砂 | 说明 |
|---|---|---|---|
| 静置 | 0 | 100% | 跟着整片仓库呼吸起伏 |
| 悬停 | +0.25 | 100% | 只有鼠标才有 |
| 当前选中 | +0.5 | 85% | 透出更多颜色，取景框角标锁定它 |
| 读取中 | 升到架子上方，转正面向镜头 | 100% → 0% | 读卡头扫过 |
| 已读取 | 停在特写位 | 0% | 可以拖动它转 ±35° 看侧面，松手回正 |
| 插入 | 竖直下沉出画面 | 0% | 见 §9.4 |
| 退回 | 先转正，再落回架子 | 0% → 100% | 沿用参考作品"先转正、再下降"的规矩，避免穿插 |

## 7. 活的核心

**共同规则**：每个核心是一段 Canvas 2D 绘制程序（512×512，手机上 256×256），在 3D 里当贴图用，在 2D 降级版里直接显示。它接收这些输入：时间、指针相对卡带的位置、清晰度、是否被选中、音频时钟。

磨砂时只看得到颜色和大形，清晰后细节全部出来。所以每个核心都按**"糊着也认得出，清楚了有惊喜"**来设计。

### beat · 节拍幸存者

- **糊着**：一团品红 / 青色的同心光环，按 128 BPM 一明一暗
- **清晰后**：4 圈同心环，外面一圈 32 根频谱刻度
  - 每拍底鼓从中心推出一道冲击环（对应游戏里"底鼓 = 冲击波"）
  - 反拍的踩镲让外圈刻度闪一下
  - 每 4 小节换一次颜色主次（品红为主 ↔ 青为主）
- **声音**：读取完成后（声音开着时），很小声地放一段 128 BPM 的合成小节（底鼓、踩镲、贝斯琶音，同一调式）。环跟着 AudioContext 的时钟走，不跟画面帧走
- **小互动**：在 beat 卡带上跟着拍子点 4 下，整片仓库就按你点的速度起伏（彩蛋）

### stay · 别关我

- **糊着**：一个乳白的圆点，偶尔"眨"一下（亮度闪一下）
- **清晰后**：一只极简的眼睛，细线眼眶 + 墨色瞳孔
  - 瞳孔追着鼠标或手指
  - 隔几秒眨一次眼
  - 你盯着它不动太久，它会害羞地把视线移开
- **挽留**：
  - 你从 stay 翻到下一盒时，它的眼睛追着你翻走的方向看，HUD 小字跟一句"……要走了吗"
  - 你切走标签页再回来，它说"你刚才去哪了"（每个会话一次）
- **语气**：短句、省略号、不打扰，和游戏里"不想被关掉的网页"一致。颜色只有墨、纸和一点点情绪粉

### dot · 从一个点开始

- **糊着**：真的只有一个像素大小的绿点。在一片乳白里，它反而最显眼
- **读取时**：清晰前沿每扫过一段，点就进化一个时代：
  1. 终端：`>_` 闪烁光标，"1 bit"
  2. 黑白矢量：一个小 Pong 球在弹
  3. 8-bit：NES 调色板的像素小人
  4. 16-bit：有视差的小风景
  5. 辉光：霓虹粒子
  6. 3D：一个旋转的线框 / 实体立方体（Canvas 自己做投影）
- **清晰后**：停在 3D 展示几秒，然后"啵"地缩回一个点，再循环一遍（"从一个点开始"）
- **声音**：每进化一次就有一个短音，音色跟着时代走：蜂鸣 → 方波 → chiptune → FM → 合成器 → 氛围垫音

### 空白卡带 ·「下一盒」

- **磨砂和清晰都一样**：空的核心井，一圈虚线，中间一个慢慢闪的"+"
- **读取后的文案**："空白卡带。还没有刻录任何东西，下一个游戏正在构思。"
- **插入**：卡带进去又被吐出来，"里面什么都没有。"（还有个彩蛋，见 §14）

### 通用核心（新游戏不写代码也能用）

- 按数据里的 `color` / `color2` 和 `glyph`（一个字，或一段 SVG path）自动生成：圆井里一枚发光的字或图形，外面一圈绕行的刻度，按 `pulse`（BPM，可选）呼吸
- 想要专属核心时，再在 `src/cores/` 里加一个文件，并在数据里写上 `"core": "xxx"`

## 8. 阵列：只有 3 个游戏时怎么撑满

考虑过三种方案：

| 方案 | 做法 | 结论 |
|---|---|---|
| **A. 主架循环 + 空白库存** | 中间一条主架循环放 [beat, stay, dot, 下一盒]；两侧几排架子装满还没刻录的空白卡带（灯灭、没有核心） | **采用** |
| B. 按状态分列 | 已上线 / 开发中 / 构想各占一列 | 现在三个游戏都在开发中，另外两列要么空着，要么得公开还没宣布的点子 |
| C. 每个游戏一列 | 列内放版本、开发日志、截图卡带 | 内容负担太大；以后可以做成"开发日志卡带"（见 §17） |

方案 A 的画面：一片乳白的玻璃卡带仓库，只有中间一条架子亮着三种颜色。视线自然聚焦，游戏一眼就能认出来，也顺便说明了"游戏还不多，但仓库很大，以后会一盒盒亮起来"。

细节：

- **主架循环**：循环周期 = 游戏数 + 1（空白卡带）。往哪个方向一直翻都不会到头；循环寻址用 `nearestOccurrence`，翻过头也不会倒退
- **空白库存不完全一样**：随机挑少数几盒做出细微差别（标签空白、灯是没通电的暗红、个别稍微歪一点），避免死板
- **横向拖动**：只有一条主架时，横向拖动有橡皮筋手感，松手弹回主架。以后游戏超过 8 个左右，按数据里的 `shelf` 分成几条亮着的架子，横向就能切架。代码按"架子列表"来写，现在列表里只有一条
- **整体动态**：停手 2.5 秒后整片仓库缓慢呼吸；选中或切换时，波浪从选中的卡带传开；读取 beat 时，全场跟着节拍轻轻一颤
- **一望无际**（v0.2）：每一帧按镜头视锥和雾的远端算出该画的架子和卡位，整片仓库铺满任何比例的屏幕，远处慢慢淡进背景，看不到边
- **更有生气**（v0.2）：
  - 选中的卡带用自己的颜色照亮周围的卡带：浅色主题像有色光打在白玻璃上，深色主题像霓虹发光；画面上再叠一层同色的大气光晕
  - 浏览时镜头缓慢漂移，鼠标带一点视差
  - 选中 beat 时，整片仓库轻轻跟着 128 BPM 动
  - 主架每隔几秒有一道"跑道灯"从选中的卡带向两头跑出去
  - 选中的卡带抬得更高、磨砂更薄，露出更多核心；读完时卡面扫过一道高光，伴随一串玻璃和弦

## 9. 交互流程

```
打开 ─▶ 开始 ─▶ 开场（约 8.5 秒，可跳过）─▶ 仓库（浏览）─▶ 读取（特写 + 解密）─▶ 插入 ─┬▶ 可游玩：转场 → 跳到子域名
                                      ▲                │                         └▶ 开发中：读取失败演出 → 卡带弹出
                                      └──── 返回 Esc ───┘
```

### 9.1 开场（v0.2.1：克制精致；v0.2.2：过渡改成推近 → 显形 → 拉远）

浏览器只有在用户点击或按键之后才允许发声，所以开场从一个**开始画面**开始，把这一下点击做成「开始」：

- **开始画面**：跟随明暗主题（浅色是白底黑细线，深色是黑底白细线）。中间一圈 1px 细环在缓慢呼吸，环心是品牌红点；下面是宽字距的「轻触开始」和一行小字「SOUND ON · 有声音」，再下面是「静音进入」。3D 资源在这段时间里加载，环下有一条 1px 进度线。点画面任意处、回车或空格都算开始；9 秒没人点就静音自动开演
- **开始后的时间轴**：

  | 时刻 | 画面 | 声音 |
  |---|---|---|
  | 0.1–0.9 秒 | 一道发丝线从中间展开，再收拢到起笔点 | 一口很轻的气息 + 柔和的低音 |
  | 0.8–2.0 秒 | 笔尖沿轮廓描出卡带（1px 发丝线，笔尖是一个小实心点，没有火花、没有辉光） | 一层几乎听不见的五度和声 |
  | 2.0–2.4 秒 | 线宽"上墨"到正式粗细，补上贴签横线 | |
  | 2.3 秒 | 红点轻轻落下（缓出，不回弹），外面一圈很淡的环慢慢散开 | 一声干净的单音铃 |
  | 2.45–3.35 秒 | 「铭刻」从左到右缓缓显出（宽羽化遮罩），下方一条细线同步展开；副标题字距从很宽收拢到正常；网址最后淡入 | |
  | 3.5–4.6 秒 | **推近**：「铭刻」淡出，整组标志像镜头推进一样放大（绕一个不动点、按对数缩放，看起来匀速）；轮廓收成 1px 细线、圆角收成卡带实物的圆角，正好落在 3D 卡带正面的边上。这段背景一直不透明，3D 不会提前露出来 | 一阵柔和的空气 |
  | 4.6–5.45 秒 | **显形**：红点化开，背景以红点为圆心向外镂空，一圈很淡的细线波纹跟着前沿往外走，素白的玻璃卡带从里面显出来；细线轮廓交给卡带自己的玻璃边后淡出，玻璃上扫过一道柔光 | 低频暖垫慢慢起来，一层和声慢慢打开 |
  | 5.1–8.5 秒 | **拉远**：显形还没收尾镜头就开始动（动作重叠，不会停一下再动）；先抬高、转开再拉远，镜头目标点跟着悬浮的卡带一起往下走，卡带一直留在画面中间、落回卡位；四周的卡带从雾里淡出、轻轻升起，颜色光和背景光晕这时才亮起来 | 零星几声很轻的玻璃声，暖垫慢慢落下 |
  | 约 7.5 秒 | HUD 分批淡入 | |

- **跳过**：右下角「跳过」或 Esc，剩下的部分 3.5 倍速快进。没开声音时，下方有「开启声音」可以补开
- **2D 版**：同样推近、贴合到最前面那张卡片上再显形；其余卡片随后轻轻升起、淡入（1.6 秒）
- 同一会话再次打开不播开场：镜头从特写自然拉开，卡带从雾里淡出；`?boot` 强制播放；长按标志重播；"减少动态效果"时不播
- 3D 还没准备好时，停在标志上显示「正在接入卡带库…」，好了再继续

### 9.2 浏览

- 默认选中主架第一盒；URL 带 `#beat` 时选中对应那盒
- 切换时：
  - 选中的卡带浅抬起，前一盒落回，波浪传开，伴随一声玻璃轻碰
  - HUD 的编号和标题滚动更新
  - 取景框角标跟到新卡带上

| 动作 | 桌面 | 手机 |
|---|---|---|
| 上一盒 / 下一盒 | ↑↓、W/S、滚轮、拖动 | 上下滑（带惯性） |
| 选中某一盒 | 点它 | 点它 |
| 读取 | Enter、点已选中的卡带、「读取卡带」按钮 | 点已选中的卡带、按钮 |
| 插入 | 已读取时按 Enter、按钮 | 按钮 |
| 返回 | Esc、返回按钮 | 返回按钮 |

### 9.3 读取（约 1.6 秒）

1. 卡带升出架子（临界阻尼，不回弹），镜头转到特写构图：桌面是卡带在左、正文在右；竖屏是卡带在上、正文在下
2. 卡带转正、面向镜头，读卡头红线从顶部扫到底部（约 1 秒）。扫过的地方变清晰，核心随之"活"过来；dot 在这期间一层层进化
3. 正文同时解密：主题色墨块按行滑走，标题滚动到位
4. 读完后可以拖动卡带，转着看侧面（±35°，松手回正）

**正文内容**：

- 编号 `MK-01`、中文名（大字）、英文名、一句话
- 字段：类型 / 一局时长 / 操作 / 建议设备 / 状态 / 地址
- 2–3 句简介
- 按钮：「插入卡带」「复制链接」「返回」

### 9.4 插入

先是共同动作：卡带转成竖直，对准画面下沿的卡槽（HUD 里的一条细线变成发光的槽口），往下滑进去，"咔哒"一声。之后按状态分三种结局：

- **可游玩**：
  - 槽口灯变绿，屏幕被这个游戏的核心铺满：beat 是冲击环一圈圈扩满屏，stay 是眼睛睁开占满屏，dot 是一个像素放大成整屏
  - 然后跳转到子域名，全程约 1.2 秒
- **开发中**：
  - 等宽小字逐行打出：「读取 MK-01…」「校验卡带……失败」「原因：仍在刻录中（开发中）」
  - 槽口红灯闪两下，卡带"咔"地弹出来，回到特写位
  - 下面跟一句"做好了，它会在这里亮起来。"，并突出「复制链接」（可以先把地址发到电脑上）
  - **不跳转，不是死链接**
- **空白卡带**：插进去又被吐出来，"里面什么都没有。"

**从游戏返回**：从游戏按浏览器返回、页面从缓存恢复时，清掉转场遮罩，回到这盒卡带的"已读取"状态。

## 10. 手机与微信

- **布局**：
  - 竖屏上图下文，正文区从屏高约 58% 处开始，可以滚动
  - 横屏手机用桌面的压缩版
  - 用 `100dvh` 和安全区 `env(safe-area-inset-*)`
- **手势**：
  - 上下滑翻卡带（阈值约 30px，主方向至少是次方向的 1.3 倍，参考值），带惯性
  - 轻点选中或读取
  - 场景区域阻止默认滚动，防止微信下拉露出"网页由…提供"，也防止 iOS 回弹；正文区正常滚动
- **触控目标**不小于 44px，主要按钮放在底部拇指区
- **建议电脑游玩**：数据里 `device: "desktop"` 的游戏，卡片和正文都标"建议电脑游玩"；手机上插入之前提示一次，并突出「复制链接」
- **微信**：
  - iOS 的 WKWebView 和安卓的 XWeb 都支持 WebGL2
  - 不自动播放声音
  - 不用任何需要公众号的 JS-SDK
- **省电**：页面隐藏时停止渲染；没有交互时手机降到 30fps；正文往下滚、场景移出视口时也降帧
- **省流量**：检测到 `navigator.connection.saveData` 时直接走 2D 版

## 11. 降级

| 档位 | 条件 | 表现 |
|---|---|---|
| 完整 3D | 桌面、有 WebGL2 | 全部效果；像素比 ≤ 2；卡带海按视锥铺满，最多 3400 盒 |
| 轻量 3D | 触屏设备（手机、平板） | 像素比 ≤ 1.5；最多 1900 盒；核心贴图 384 / 图集 96 |
| 动态画质 | 3D 平均低于约 27fps | 渲染分辨率逐级降低，到底后缩短视距（少画远处的卡带），都不够才切 2D |
| 2D 版 | 没有 WebGL2、上下文丢失、3D 降到最低画质后仍低于 20fps、开了省流量、用户手动选择 | 同一套 HUD。中间是「一叠卡」：选中的在最前，后面的往下往后缩、露出贴签；磨砂是模糊过的核心画布叠在清晰画布上，读取时遮罩自上而下擦清 |
| 静态版 | 系统开启了"减少动态效果" | 2D 版去掉全部自动动画：核心只画一帧代表画面；切换是 150ms 淡入淡出；插入直接跳转，或直接显示"开发中" |
| 无 JS | 禁用了脚本，或脚本加载失败 | `<noscript>` 里的游戏列表（名称、一句话、状态、链接）。构建时从数据生成，也给搜索引擎和读屏软件用 |

「关于」里有 3D / 2D 手动切换，会记住选择。

## 12. 声音

- 全部用 WebAudio 现场合成，零音频文件
- **音效**：

  | 动作 | 声音 |
  |---|---|
  | 翻卡带 | 玻璃轻碰：几个不等间隔的高频分音，快速衰减，音高随机微调 |
  | 抬起 | 很轻的气声 |
  | 读卡头 | 低频扫描嗡声 + 解码小哔声 |
  | 插入 | 咔哒：噪声脉冲 + 低频 |
  | 弹出 | 插入的反向 |
  | 空白卡带 | 空洞的回声 |
  | 读完 | 一串上行的玻璃和弦 |
  | 开场 | 见 §9.1 的时间轴 |

- **音乐**：只有读取 beat 时有一小段节拍，dot 进化时有对应时代音色的短音。不放全局背景音乐，保持安静、加载轻
- **默认**：音效开、音量小。浏览器只有在点击或按键之后才允许发声，所以第一次进入靠开场的「开始」解锁；不播开场时（同一会话再次打开），第一次触摸或按键就会解锁（滚轮不算）。iOS / 微信要在手势里放一个静音样本才算真正解锁，已处理。HUD 一键静音，并记住选择
- beat 的节拍用音频时钟调度，画面对齐音频时钟（和节拍幸存者本体同一原则）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | 小写英文，唯一；也用作深链 `#id` |

| `order` / `hidden` | 可选 | 排序 / 隐藏 |

|---|---|---|---|

## 16. 技术方案

**栈**：Vite + TypeScript + three.js（只按需引入用到的类），不用前端框架（DOM 很少，手写）。

**启动顺序**：

1. HTML 自带内联关键 CSS 和开场 SVG，先开始播开场
2. `main` 脚本运行：HUD、数据、核心、2D 版、音频
3. 同时探测 WebGL2；支持就懒加载 3D 包

**构建产物**（`dist/`）：

| 文件 | 内容 |
|---|---|
| `index.html` | 内联关键 CSS、开场 SVG、noscript 列表、meta |
| `assets/main.js` | 经典脚本（不是 module） |
| `assets/scene3d.js` | 经典脚本；main 运行后插入 `<script>` 标签懒加载 |
| `favicon.svg` `og.jpg` `apple-touch-icon.png` `licenses/` | 图标、分享图、许可文本 |

- 全部使用相对路径，所以**双击 `dist/index.html` 就能看**；放到 Cloudflare Pages 的根路径也一样能用
- 做法：Vite 分两次构建（主包、3D 包），各输出 IIFE；开发时照常用 Vite dev server 热更新
- 为什么不用 module 脚本：双击打开（`file://`）时，浏览器会按跨域拦掉 module 脚本

**目录**：

```
index.html
content/games.json          ← 数据，加游戏只改这里
public/                     favicon.svg、og.jpg、licenses/
src/
  main.ts                   启动、状态机、选择渲染档位
  data.ts                   读数据 + 校验 + 生成编号
  boot.ts                   开场
  hud/                      HUD、滚动数字、正文面板、解密墨块、取景框
  cores/                    beat / stay / dot / blank / generic（Canvas 2D，3D 和 2D 共用）
  scene3d/                  场景、卡带几何、架子与阵列、视差磨砂着色器、镜头
  fallback2d/               2D 版和静态版
  audio.ts                  WebAudio 合成
  motion.ts                 摘自 RhineLabUI（保留 MIT 声明）
  input/drag.ts             改编自 RhineLabUI（保留 MIT 声明）
  easter-eggs.ts
scripts/                    check-data（校验数据）、shoot-og（截分享图）、selftest（自测截图）
docs/                       方案.md、设计.md、开发说明.md
```

**性能预算**（gzip 后）：

| 项目 | 预算 |
|---|---|
| HTML + 内联 CSS + 字体 | ≤ 45KB |
| 主包 | ≤ 60KB |
| 3D 包 | ≤ 180KB |
| 合计 | ≤ 300KB（RhineLabUI 约 34 MiB） |
| 首屏可见（4G） | < 1 秒 |
| 可交互 | < 3 秒 |

**浏览器支持**：近两年的 Chrome / Edge / Safari / Firefox、iOS 15+、微信和抖音的内置浏览器。没有 WebGL2 时走 2D 版。

**自测**：用 Playwright + Edge 跑四种情况，各截图检查：

1. 桌面 1920×1080
2. 手机 375×812（触控）
3. 减少动态效果
4. 禁用 WebGL

**摘用代码的许可处理**：`src/motion.ts`、`src/input/drag.ts` 文件头写明"改编自 RhineLabUI 的某某文件，Copyright (c) 2026 LBEILC，MIT License"，MIT 全文放在 `public/licenses/RhineLabUI-MIT.txt`，「关于」里列出致谢。

## 19. 实现时的调整

- **雾改成透明**：远处的卡带直接融进页面的 CSS 渐变背景，不再混成一个雾色。读取时雾会拉近，让背景退开、把注意力留给这盒卡带
- **触屏翻页**：仓库很密，手指 1:1 跟手的话一滑就是十几盒。现在一个卡位在屏幕上至少按 100px 算；短滑一下正好翻一盒，用力甩才连翻
- **点选中的卡带**：它的下半截常被前排卡带挡住，所以点在它外框的上部就算点中
- **轻量 3D**：只给触屏设备；笔记本小屏照样用完整 3D，卡顿时自动降到 2D
- **彩蛋卡带**：状态标签显示「彩蛋」，读取后的正文里有制作说明和致谢
- **v0.2.2（用户反馈「过渡不自然」）**：原来的「入盒」是一边放大标志、一边把背景淡掉，露出早就停在那里的 3D 特写：两层画面交叉淡化、大小差 5 倍以上，卡带还带着粉色光，之后特写停一下才开始拉远，卡带又在很低的机位下"沉"进前排。改成三段接力（§9.1）：推近（背景不透明，轮廓精确落到卡带边上）→ 显形（红点化开成波纹，卡带从里面显出来）→ 拉远（和显形重叠起步，转角领先、目标点跟着卡带走）；特写时去掉颜色光和背景光晕，点亮波开始才亮；特写的卡带从占画面 80% 缩到 50%，放大倍数没那么猛
- **v0.2.1（用户反馈「开局不够高级」）**：开场保留原结构，改成克制精致的风格（§9.1）：去掉火花、红色激光辉光、白闪和标题乱码效果，改为发丝线描绘、柔光、更慢更稳的运镜，声音换成柔和的氛围音，开场跟随明暗主题；选中卡带的颜色光收弱一档。中间试过一版卡点配乐 + 低空疾驰的开场，用户认为方向不对，已撤回
- **v0.2（用户反馈「有些平淡 / 加开场 / 卡带海被截断」「不点击不会出声」）**：开场重做成「开机键 → 激光刻标志 → 入盒 → 一镜到底拉远」（§9.1）；卡带海按视锥铺满（§8）；加了颜色光、大气光晕、镜头漂移与视差、跑道灯、读完高光等（§8「更有生气」）
